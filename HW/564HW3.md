## a) Utility Class - System.Math
ตัวอย่าง:
csharp// ตัวอย่างการใช้งาน Math class
double result1 = Math.Pow(4, 2);        // 16
double result2 = Math.Sqrt(16);         // 4
double result3 = Math.Abs(-5);          // 5
double piValue = Math.PI;               // 3.14159...
วิเคราะห์ว่าเพราะเหตุใดจึงเป็น Utility Class:

เป็น Static Class - Math class ถูกประกาศเป็น static ทั้งหมด ไม่สามารถสร้าง instance ได้
มีแต่ Static Methods และ Fields - ทุก method (Pow, Sqrt, Abs) และ constant (PI, E) เป็น static
ไม่เก็บ State - ไม่มี instance fields หรือ properties ที่เก็บข้อมูล
จุดประสงค์เป็น Helper - ให้บริการฟังก์ชันทางคณิตศาสตร์ที่ใช้ร่วมกันได้
ไม่ต้องการ Object Creation - เรียกใช้งานได้ทันทีผ่าน class name เช่น Math.Pow()


b) Mutable Class - System.Text.StringBuilder
ตัวอย่าง:
csharp// ตัวอย่างการใช้งาน StringBuilder
StringBuilder sb = new StringBuilder("Hello");
sb.Append(" World");           // แก้ไข instance เดิม
sb.Insert(5, ",");             // แก้ไข instance เดิม
sb.Replace("World", "C#");     // แก้ไข instance เดิม
Console.WriteLine(sb);         // Output: "Hello, C#"
วิเคราะห์ว่าเพราะเหตุใดจึงเป็น Mutable Class:

State สามารถเปลี่ยนแปลงได้หลังสร้าง - เมื่อสร้าง StringBuilder แล้ว สามารถเปลี่ยนแปลงเนื้อหาได้
Methods แก้ไข Instance เดิม - Append(), Insert(), Replace() แก้ไขข้อมูลใน object เดิมโดยตรง ไม่สร้าง object ใหม่
ประหยัด Memory สำหรับการแก้ไขบ่อยๆ - ไม่สร้าง instance ใหม่ทุกครั้งที่แก้ไข ต่างจาก String
ใช้ Internal Buffer - เก็บข้อมูลใน char array ภายในที่สามารถขยายได้
Properties เปลี่ยนแปลงได้ - Length และ Capacity สามารถเปลี่ยนค่าได้ตลอด


c) Immutable Class - System.String
ตัวอย่าง:
csharp// ตัวอย่างการใช้งาน String (Immutable)
string str1 = "Hello";
string str2 = str1.Replace("H", "Y");  // สร้าง string ใหม่
string str3 = str1.ToUpper();          // สร้าง string ใหม่

Console.WriteLine(str1);  // "Hello" - ค่าเดิมไม่เปลี่ยน
Console.WriteLine(str2);  // "Yello" - object ใหม่
Console.WriteLine(str3);  // "HELLO" - object ใหม่
วิเคราะห์ว่าเพราะเหตุใดจึงเป็น Immutable Class:

State ไม่เปลี่ยนหลังสร้าง - เมื่อสร้าง String แล้ว ค่าไม่สามารถเปลี่ยนแปลงได้
ทุก Method สร้าง Instance ใหม่ - Replace(), ToUpper(), Substring() ทุกตัวคืนค่าเป็น String object ใหม่ ไม่แก้ไขของเดิม
Properties เป็น Read-only - ไม่มี setter สำหรับ properties ใดๆ
Thread-Safe โดยธรรมชาติ - เนื่องจากค่าไม่เปลี่ยน สามารถใช้ใน multi-threading ได้อย่างปลอดภัย
Sealed Class - String class ถูกประกาศเป็น sealed ป้องกันการ inherit และการแก้ไข behavior

ตัวอย่างเพิ่มเติมของ Immutable Class: System.DateTime
csharpDateTime dt = new DateTime(2024, 1, 1);
DateTime newDt = dt.AddDays(10);  // สร้าง DateTime ใหม่
Console.WriteLine(dt);     // 2024-01-01 - ค่าเดิมไม่เปลี่ยน
Console.WriteLine(newDt);  // 2024-01-11 - object ใหม่
